# Versiones fijadas con == para que el proyecto sea reproducible: con estas, los dos
# notebooks reproducen exactamente los numeros Y los graficos que estan guardados.
#
# Por que exactas y no >=: los resultados numericos los fija la semilla, pero el
# renderizado de los graficos no. Entre versiones de matplotlib cambian el
# antialiasing y hasta el ancho en pixeles de una figura, asi que con >= los PNG
# salen distintos aunque el analisis sea identico. Tambien pandas cambia detalles de
# la salida de info() entre versiones de parche.
#
# Ejecutado y verificado con Python 3.13.16.
# Si tu version de Python no tiene ruedas para alguna de estas, reemplaza el == por
# >= en esa linea: el analisis no cambia, los graficos se van a re-renderizar.
